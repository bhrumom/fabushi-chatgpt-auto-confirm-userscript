# 2026-09-19 — Same-chat abnormal continuation

## Persisted user requirement

当 ChatGPT 已经有本轮真实会话链接，但回复异常中断时，不得把该异常当作本轮结束，也不得清空当前 conversation URL/token 后新开会话：

1. 页面出现“消息错误，请重试”“消息发送超时，请重试”或等价可重试发送错误时，在**同一会话**输入并发送“继续完成所有”。
2. 页面出现“连接已中断。正在等待完整回复。”时保留原会话；若该状态持续超过 30 分钟，在**同一会话**输入并发送“继续完成所有”。
3. 已绑定会话没有最终回复且持续停滞时，30 分钟后也在同一会话追加“继续完成所有”；之后仍异常则继续采用同会话恢复，不能把异常恢复转换成 fresh-session retry。
4. 只有当前最新 assistant turn 出现可验证的最终回复操作栏（复制 + 分享/评价/点赞/点踩），且 Stop 不存在并稳定后，才允许 finish()。
5. finish() 后持续目标才可以按既有 Work → Review / Review → Work 流程新开下一轮会话。
6. 旧错误卡不得覆盖更新的最终回复；续发的“继续完成所有”用户 turn 必须继续归属于原 Fabushi 任务。
7. 发布新版本 2.9.40，并保留可核验的 PR、CI、canonical main 与 Release 证据。

## Non-goals

- 不改变授权卡“允许本次会话”流程。
- 不改变未绑定发送结果的安全归属策略；无法证明真实会话身份时仍不得盲目重复点击原任务。
- 不把 Stop 消失本身恢复为完成信号。
