# Fabushi 独立油猴工作台 2.7.7

这是 Fabushi 的独立油猴脚本源码仓库：
`https://github.com/bhrumom/fabushi-chatgpt-auto-confirm-userscript`。
入口文件是 `chatgpt-auto-confirm.user.js`，当前版本为 `2.7.7`。

## 使用

在 ChatGPT 页面点击 **Fabushi 脚本**。左侧选择任务，右侧查看消息、状态和实时回复；底部输入任务，选择“单次任务”或“持续目标”后发送。

- 单次任务：发送一次，确认当前轮最终回复后结束。
- 持续目标：工作会话只返回自然语言；工作结束后插件自动在同一标签页新开规划/验收会话，解析绑定任务 ID 和轮次的 JSON，完成则停止，未完成则把 `next` 原文交给新的 Work 会话。
- 会话切换：把 ChatGPT 的 `https://chatgpt.com/c/<会话ID>`（或对应 `chat.openai.com` 地址）作为唯一会话身份并持久记录，不读取也不等待侧边栏。发送后立即记录浏览器实际生成的会话链接；恢复时直接打开已记录链接，页面尚在加载只原地等待，不刷新、不重复导航，也不会因为侧栏延迟而等待 4 次。旧版的 `WEB:` 合成地址不会被强制打开；若当前页面带有本轮标识，会自动校正为真实链接。页面重载会保留正常任务的会话地址、链接历史和轮次标识，不会误判为未推进并反复新开 Chat。新建目标或恢复任务时优先处理当前选中的任务，不会被旧失效会话阻塞；旧版留下的侧栏等待记录恢复时也会直接采用已记录 URL。
- 编辑目标：选中任务后点击“编辑目标”即可修改持久化目标；正在发送的当前会话不被改写，验收中的旧 `next` 会被丢弃，下一轮 Work 使用新目标。
- 消息历史：任务消息不再截断为最近 80 条，工作台会保留并显示完整历史记录。
- 限流识别：只读取 ChatGPT 自己的可见页面提示，排除插件面板和聊天正文；插件写下的限流状态不会反过来触发新的限流等待。
- 全页面授权：在“设置”中开启后，独立扫描任何 ChatGPT 会话里的授权卡。识别只看同一卡片中的“拒绝 + 允许 + 下拉箭头”结构，完全不读取卡片正文；随后点击“允许”旁的箭头并选择本次会话选项。支持 `Allow GitHub for this conversation` 这类包含连接器名称的菜单文案，不依赖任务是否由脚本派发，也拒绝永久授权选项。
- 恢复已取消任务：选中已取消任务后点击“恢复任务”。已有持久化会话时继续监控原会话，尚未派发时回到等待队列。
- 无最终回复：已发送会话结束但没有最终回复时，插件不把空结果交给规划会话，而是新开 Chat 原样重发当前 Work/规划指令，最多自动重试 4 次；停止按钮消失后仍没有最终回复或授权卡，会在短暂稳定等待后立即走这条恢复路径；这个上限不适用于按 URL 恢复会话。
- 多个任务：同一标签页串行推进当前任务；当前 Work → 规划/验收 → 下一轮 Work 链完成前不会跳到其他任务的会话链接，因此不会因轮询打断生成或重复派发。当前任务进入完成、阻塞或取消后，才会选择下一个任务；不创建子标签页。
- 暂停：把所有未完成任务（包括需要处理的任务）明确标记为“已暂停”，取消脚本正在等待的操作和调度，不再发送、切换或点击授权。暂停带有跨标签版本屏障，旧标签页不能把运行状态写回；恢复时还原每个任务暂停前的状态并优先处理当前选中的任务，旧版“侧栏未找到”阻塞若已有 URL 会转为按链接监控。已经交给 ChatGPT 服务器的生成不会被撤回，可在 ChatGPT 点击停止回答。
- 脚本主动发起的同标签导航直接使用已记录的唯一会话链接，并凭 10 分钟内的一次性导航记录恢复；普通刷新会从已持久化的正常任务状态继续，不会清空原会话地址、链接历史或所有权标识。已完成 Work、尚未派发验收的任务恢复时不会误开上一轮链接。若 ChatGPT 路由长时间没有完成加载，只执行有限次数的单次恢复加载，随后保留发送意图等待，不会无限刷新同一页面。
- 旧版任务保留在原存储中并标记暂停，不自动导入运行。

## 完成识别

最后一条用户消息必须包含本轮随机标识。当前 assistant 回复还必须有本轮完成控件或明确结束标记、没有停止按钮、没有待授权卡，并稳定至少 4 秒。普通文字暂时不变化不算完成。若停止按钮消失后连续 15 秒仍没有最终证据或授权卡，会在新 Chat 原样恢复；重载后无法确认曾经生成时仍使用 5 分钟兜底，最多自动重试 4 次。

授权限定为匹配卡片内的箭头菜单及“允许本次会话”，选择后验证卡片解除。ChatGPT 的 Radix 分裂按钮使用 `pointerdown` 展开，插件会先发送指针动作再点击，兼容菜单项为 `div[role=menuitem]` 的真实结构。没有匹配到菜单就保持等待。授权作用于用户启用自动授权的任务。

## 资源策略

一个调度定时器，前台约 2 秒、后台约 4 秒采样；不监听全页面 MutationObserver；不运行跨标签心跳。暂停时不再周期采样。消息完整保留（每条最多 24000 字符），任务最多 50 个，实时预览截取 6000 字符。使用 Web Locks 防止两个标签页同时运行调度。
